Shape A Parting With Edit Warp¶

Applies to: Parting Placer V2.0.0 · Blender 4.4 · 5.2

Bend a parting so it follows the head, for example along a hairline, by dragging handles in the viewport.

You Need First

  • Place Partings
  • The Parting Parameters box. It shows while a parting is picked. See Parting Parameters.

Bend The Corners¶

  1. In the parting list, select the parting you want to shape.
  2. In Parting Parameters, select Edit Warp. Four handles appear on the parting.
  3. Drag a handle with the left mouse button.
  4. Press Enter to keep the shape.

To cancel instead, press Esc or right-click. The parting goes back to how it was before you selected Edit Warp.

The middle mouse button still orbits the view while you edit. A key guide in the viewport lists the keys.

Add More Handles With A Lattice¶

Four handles can't follow every curve. A lattice gives the parting a grid of handles instead.

  1. Check Edit Warp is not pressed. If it is, press Enter first.
  2. Select Convert To Lattice. The parting keeps its shape and gets a 2 x 2 lattice.
  3. Select P+ to add a column of handles.
  4. Select Q+ to add a row. The size shows underneath, for example Lattice 4 x 4.
  5. Select Edit Warp.
  6. Drag the handles to the shape you want.
  7. Press Enter to keep the shape.

Set the number of rows and columns before you start shaping. Changing the size later can shift the shape.

Each side goes up to 8 handles.

Control How Far A Drag Spreads¶

While you hold a handle, scroll to change Soft Radius. It sets how far a drag pulls the nearby handles along. At 0 only the handle you hold moves.

On a lattice, Fold Guard stops the warp folding back through itself. Hold Shift and scroll to change it.

To go back to a plain corner warp, select Reset To Corners. The lattice shape is not kept.

If You're Stuck

  • Convert To Lattice or P+ is greyed out? Press Enter to finish the edit first.
  • A parting looks doubled or folded? See A Parting Looks Doubled Or Folded.
