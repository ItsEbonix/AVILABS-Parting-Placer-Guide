Install, Update, Uninstall¶

Applies to: Parting Placer V2.0.0 · Blender 4.4 · 5.2

Install the add-on from its .zip file and find its panel in the 3D Viewport.

You Need First

  • The add-on .zip file from your purchase.
  • A Blender version from Requirements And Compatibility.

Install¶

  1. In Blender, open Edit > Preferences.
  2. Select Add-ons.
  3. Select the down arrow at the top right of the Add-ons section, beside Enabled Only.
  4. Select Install from Disk....
  5. Pick the add-on .zip file.
  6. Enable Parting Placer Tool in the add-on list.
  7. In the 3D Viewport, press N to open the sidebar.
  8. Select the Parting Placer tab.

Update¶

Install the new version over the old one. You don't need to uninstall first.

  1. Open Edit > Preferences.
  2. Select Add-ons.
  3. Select the down arrow at the top right of the Add-ons section.
  4. Select Install from Disk....
  5. Pick the new add-on .zip file.

After updating, open each file that already has partings. Select Repair Partings once in that file. See Repair Partings.

Uninstall¶

  1. Open Edit > Preferences.
  2. Select Get Extensions.
  3. Find Parting Placer Tool in the Installed list.
  4. Select the down arrow at the right of its row.
  5. Select Uninstall.

Partings already in your files stay where they are and still show on the head. Without the add-on you can't edit them from the panel.

If You're Stuck

  • Still stuck after installing? See Still Stuck.
